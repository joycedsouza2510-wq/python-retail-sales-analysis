# Retail Sales Analysis with Python

## Project Overview

This project demonstrates an exploratory data analysis (EDA) of retail sales data using Python. The objective is to understand product performance, compare regional revenue, calculate profitability metrics, and communicate findings through visualisations.

I developed this project as a beginner data analytics portfolio piece using a small, synthetic retail dataset.

## Business Questions

- Which products generate the most revenue?
- Which regions contribute the most sales?
- Which products generate the highest gross profit?
- What is the overall gross profit margin?
- How can data visualisation support business decisions?

## Tools and Technologies

- **Python** — data analysis and calculations
- **Pandas** — data manipulation, grouping and aggregation
- **Matplotlib** — data visualisation
- **Google Colab / Jupyter Notebook** — interactive development
- **GitHub** — project versioning and portfolio presentation

## Project Workflow

1. Loaded retail transaction data from a CSV file.
2. Inspected the dataset structure and data types.
3. Practised data cleaning, including duplicate detection, missing values and text standardisation.
4. Calculated sales revenue and gross profit.
5. Grouped transactions by product and region.
6. Calculated business KPIs, including gross profit margin and average order value.
7. Created charts to compare product and regional performance.
8. Summarised findings and developed business recommendations.

**Definitions**

- Revenue = Quantity × Unit Price
- Gross Profit = Quantity × (Unit Price − Cost per Unit)
- Gross Profit Margin = (Gross Profit ÷ Revenue) × 100
- Average Order Value = Total Revenue ÷ Number of Transactions

2. Upload the sample CSV file if required.
3. Run the notebook cells in order.
4. Review the analysis, KPI calculations, and charts.

The project uses Python libraries including Pandas and Matplotlib.

## Limitations

- The dataset contains only 10 sample transactions.
- The data is synthetic and does not represent a real company.
- Gross profit excludes other operating expenses.
- The findings are descriptive and do not establish causation.
